# Piper TTS для Windows — Озвучивание выделенного текста по горячим клавишам

Готовое портативное решение для мгновенной озвучки любого выделенного текста в Windows (в браузере, мессенджерах, Word, PDF, блокноте) по нажатию горячих клавиш.

Работает **локально, оффлайн, без задержек и без необходимости что-либо компилировать или устанавливать в систему**.

---

## ⚡ Быстрый старт (всё уже настроено в этой папке)

1. Запустите **`start_piper.vbs`** (двойным кликом) — скрипт запустится в фоновом режиме, а в системном трее появится иконка.
2. Выделите любой текст в любой программе.
3. Нажмите **`Ctrl + Shift + Space`** — текст озвучится!
4. Чтобы **остановить чтение** — нажмите то же сочетание **`Ctrl + Shift + Space`** (или `Ctrl + Shift + Esc` / клавишу `Pause`).

> **Совет:** Чтобы запускать без консольных окон, используйте `start_piper.vbs`. Если хотите видеть сообщения в консоли, используйте `start_piper.bat`.

---

## 🎛 Возможности и меню в системном трее

Кликните правой кнопкой мыши по иконке Piper в трее (около часов):

* **Настроить горячую клавишу:** Открывает графическое окно, где можно нажать любое желаемое сочетание клавиш или выбрать пресет. Настройка сразу применяется и сохраняется в `config.ini`.
* **Выбор голоса:** Переключение между установленными моделями на лету (по умолчанию в папке уже лежат *Дмитрий* и *Ирина*).
* **Скорость речи:** 1.0x (Нормальная), 1.2x (Быстрая), 1.4x (Очень быстрая), 0.85x (Медленная).
* **Добавить в автозагрузку Windows:** Создает ярлык в папке автозагрузки (`shell:startup`) в один клик.
* **Открыть папку с моделями:** Быстрый доступ к папке `models/` для добавления новых голосов.

---

## 🗣 Как добавить другие голоса

В папку `models/` можно положить любые голоса для Piper (формат `.onnx` и `.onnx.json`):

1. **Автоматически:** Запустите в PowerShell скрипт:
   ```powershell
   .\download_voice.ps1
   ```
   и выберите нужный номер голоса (Русский Денис, Руслан, Английский Lessac, Ryan и др.).
2. **Вручную:** Скачайте любые модели из официального каталога [HuggingFace Piper Voices](https://huggingface.co/rhasspy/piper-voices/tree/main) и скопируйте оба файла (`.onnx` и `.onnx.json`) в папку `models/`. Они автоматически появятся в меню трея!

## 📂 Структура каталога

```text
piper_tts/
├── piper/                 # Официальный портативный бинарник piper.exe (C++ + ONNX Runtime)
├── models/                # Голосовые модели (ru_RU-dmitri-medium, ru_RU-irina-medium)
├── ahk/                   # Портативный интерпретатор AutoHotkey v2 (не требует установки)
├── speak_selected.ahk     # Скрипт перехвата горячих клавиш и синтеза
├── start_piper.vbs        # Фоновый тихий запуск (рекомендуется)
├── start_piper.bat        # Запуск через CMD
├── stop_piper.bat         # Остановка фонового процесса
├── download_voice.ps1     # Скрипт загрузки дополнительных голосов
└── piper_hotkey.py        # Альтернативный скрипт на чистом Python (для разработчиков)
```

## 💡 Почему AutoHotkey и VBScript (Обоснование выбора технологий)

При проектировании решения ключевыми требованиями были **максимальная простота («скачал и работает»), надёжность в любых программах Windows и минимальное потребление ресурсов**.

### 1. Почему AutoHotkey v2 (а не Python / C# / Electron)?
* **Zero-install и портативность:** Интерпретатор `AutoHotkey64.exe` весит всего 1.2 МБ и запускается автономно без прав администратора, без установки сторонних сред выполнения (.NET / Python runtime) и без загрязнения реестра.
* **Минимальный след в памяти:** Фоновый процесс потребляет всего **~10–15 МБ RAM** (для сравнения: фоновый Python с библиотеками требует 50–80 МБ, а приложения на Electron — от 150–300 МБ).
* **Глубокая и стабильная интеграция с Windows API:**
  * Низкоуровневые клавиатурные хуки надёжно перехватывают глобальные комбинации клавиш поверх абсолютно любых окон (включая полноэкранные приложения, браузеры и терминалы).
  * Корректная работа с буфером обмена: AHK мгновенно перехватывает выделенный текст через `Send("^c")`, сохраняя и сразу восстанавливая исходный буфер пользователя (`ClipboardAll()`), благодаря чему ваши ранее скопированные данные не теряются.
  * Аппаратное маскирование раскладки: AHK позволяет на лету инжектировать виртуальный сканкод (`vkE8`), предотвращая ложное переключение языка ввода в Windows при нажатии комбинации `Ctrl+Shift`.
* **Встроенный аудиоконтроль и трей:**
  * Управление воспроизведением осуществляется через нативный Windows MCI API (`winmm\mciSendStringW`) с возможностью мгновенного старта, остановки и проверки статуса («играет / остановлено») без необходимости тащить тяжелые внешние аудиоплееры.
  * Легковесное контекстное меню в трее Windows со сменой голосов, скорости и автозагрузкой.

### 2. Почему VBScript (`start_piper.vbs`) (а не обычный `.bat`)?
* **Абсолютно бесшумный запуск (SW_HIDE):** В Windows запуск обычных `.bat` / `.cmd` файлов неизбежно вызывает кратковременное мелькание черного окна командной строки.
* **Штатный компонент Windows (0 сторонних утилит):** Windows Script Host (`wscript.exe`) встроен во все версии Windows «из коробки» начиная с Windows 98.
* Вызов `WshShell.Run "...", 0, False` запускает процесс в скрытом режиме (`0 = SW_HIDE`), благодаря чему Piper TTS бесшовно стартует прямо в системный трей без всплывающих консольных окон (что критично для комфортной работы и при старте из автозагрузки).

## 🐍 Альтернатива: Установка через Python (pip)

Если вы хотите использовать Piper через Python-библиотеку из репозитория [OHF-Voice/piper1-gpl](https://github.com/OHF-Voice/piper1-gpl):

1. Убедитесь, что у вас установлен **Python 3.9 – 3.12** (64-bit).
2. Установите Piper:
   ```cmd
   pip install piper-tts
   ```
3. Установите зависимости для скрипта горячих клавиш:
   ```cmd
   pip install keyboard pyperclip
   ```
4. Запустите готовый скрипт:
   ```cmd
   pythonw piper_hotkey.py
   ```
